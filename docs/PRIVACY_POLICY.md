# 甘农卡隐私政策

生效日期：2026 年 10 月 12 日

甘农卡是本地运行的付款码工具，不提供账号注册、广告、统计分析或个性化推荐。

## 应用保存的信息

应用会在本机保存已添加卡片的绑定信息，包括绑定链接中的 `openid` 和卡片 id、学校页面返回的姓名和卡号、余额、短期付款码及其获取时间、用户备注，以及主题和后台刷新设置。这些数据用于显示卡片、请求学校付款码、刷新桌面组件和恢复用户设置。付款码是短期凭证，过期后不会再作为有效付款码使用。

上述数据保存在应用私有存储。应用已关闭 Android 系统备份，且没有对本地配置做额外加密；获得本机文件或调试权限的人可能读取这些信息。请使用系统锁屏，不要把绑定链接或配置文件交给不可信的人。

## 网络传输

刷新付款码时，应用会把卡片标识和必要请求信息发送到甘肃农业大学一卡通服务器 `yktapp.gsau.edu.cn`。学校服务器可能按照其自身规则记录 IP 地址、请求时间、User-Agent、访问日志和页面会话信息，应用无法控制学校服务器的保存期限和使用方式。

检查更新和加载操作引导图片时，应用会访问 `gh.re-tikara.fun` 的 Cloudflare Worker；该 Worker 会代为请求 GitHub 上的公开 Release 或图片资源。更新和引导请求不会携带卡片绑定链接、openid、付款码或余额。应用没有接入广告、崩溃统计、行为分析或第三方账号登录。Cloudflare、GitHub 和学校服务器分别受其自身隐私规则约束。

## 导出与分享

导出的 JSON 配置包含绑定链接、openid、卡片 id、姓名、卡号、备注和当前卡片位置，不包含付款码和余额。文件由系统文件选择器写入用户指定的位置，采用明文格式，应用不会替用户加密、上传或删除它。

长按二维码分享时，应用会在本机缓存目录生成 PNG，并通过 Android 系统分享面板交给用户选择的应用。图片包含当时的付款码；分享目标应用可能保存、上传或转发图片。应用会保留已交给分享目标读取的图片最多 24 小时，失败或取消时立即清理，应用启动和再次分享前会清理过期文件。

## 权限和删除

网络权限用于访问学校服务器、更新代理和引导图片；通知、前台服务、电池优化和自启动相关设置用于后台刷新；闹钟和提醒权限只用于付款码到期时清除桌面组件上的二维码。应用不会主动读取或上传剪贴板内容。

删除卡片会删除应用私有存储中的该卡片记录及其本地缓存，但不会删除已经导出的文件、已经分享给其他应用的图片，也不能撤回学校服务器或其他应用已经保存的数据。清除应用数据或卸载应用可删除应用私有存储；系统分享目标、文件管理器和备份介质中的副本需要由用户自行处理。

如需查询、更正或反馈本应用的数据处理方式，请联系 `163mail@re-tikara.fun`。学校账户、校园卡和第三方服务相关的数据请求应向相应服务提供方提出。政策发生重要变化时，会随应用版本更新。

本政策只说明甘农卡当前版本的处理方式，不代替学校、Cloudflare 或 GitHub 的隐私政策。
